How to use and what the tool checks
  1. Load the previous and new SRS Excel files (first sheet, header in row 1 – detected automatically).
  2. Optionally load the last delta workbook you produced: its Revision History is copied and the revision number moves up by one.
  3. Check the column pairing. Columns are paired by header name; the requirement text column (e.g. “SRS_11.00” / “SRS_11.01”) is paired as Description.
  4. Enter the revision description, run the comparison, review the on-screen results and download the workbook.

Rules: requirements are matched by ID. IDs only in the new file are New, only in the previous file Deleted. A requirement is Modified if any selected factor differs after ignoring spaces, line breaks, tabs, punctuation (. , ; : ! ? quotes, dashes, bullets, brackets, underscore) and – if ticked – letter case. Symbols such as < > = / % are kept because they can change meaning. Formula cells are compared on their saved values.
